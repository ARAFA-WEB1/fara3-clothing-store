## ✨ Features

- 🛒 **Shopping Cart** — Add, remove, and update item quantities
- 👤 **User Authentication** — Sign Up / Login / Logout system
- 🌙 **Dark / Light Mode** — Toggle between themes
- 👗 **Collections Gallery** — Browse products by category
- 💳 **Checkout System** — Visa, PayPal, Cash on Delivery
- 📦 **Order History** — View all previous orders with details
- 📱 **Fully Responsive** — Works on Mobile & Desktop
- ✅ **Form Validation** — Real-time input validation with jQuery

## 🚀 How to Run

**1. Clone the repository**
```bash
git clone https://github.com/ARAFA-WEB1/fara3-clothing-store.git
```

**2. Open the project**
```bash
cd fara3-clothing-store
```

**3. Run it**
- Simply open `web3.html` in your browser
- Or use **Live Server** extension in VS Code
